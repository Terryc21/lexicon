Swift concurrency

async marks an asynchronous function and await marks a possible suspension point.

Actor isolation restricts access to actor-owned state. Example: actor Counter { var count = 0 }.

Actor reentrancy allows another call to use an actor while an earlier call is suspended. Example: read count, await a save, then re-check count.

Sendable describes values that can safely cross concurrency isolation boundaries. Example: struct Point: Sendable { let x: Int }.

Structured concurrency ties child tasks to their parent scope. Example: async let first = loadFirst().

Task cancellation is cooperative: a task must check cancellation to stop early. Example: try Task.checkCancellation().

A task group manages a dynamic collection of child tasks within a scope. Example: withTaskGroup(of: Int.self) { group in ... }.

A continuation bridges callback-based code to an asynchronous function. Example: withCheckedContinuation { continuation in ... }.
